# Rook CEO Decision Room

A static executive research dashboard for the fictional Product School course scenario. Open `dist/index.html` locally or serve `dist/` with a static HTTP server.

Source snapshot: all 147 support tickets, 29 June–7 September 2026, and four interviews, 2–5 September 2026. `dist/data.js` preserves source ticket text and the affinity-map coding. The dashboard is not a live connector.

Filters select product and filing period. Cards and the channel comparison explicitly use the full dataset. Cluster counts overlap (#3110 and #3140 are in two clusters); ticket metrics count unique ticket IDs. The before/after rate uses 44 and 26 calendar days, with 12 August separate. Personal decision drafts use browser-local storage only.

No revenue, churn, operational acceptance rates, causal claims or organizational commitments are inferred from this evidence. Miro links lead back to evidence clusters. CSV export follows the evidence table's current scope, search and cluster filter.
